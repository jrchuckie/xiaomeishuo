# 小美说本地 App 原型

一套可安装的 PWA 原型：从用户授权的审美样本中生成个人审美画像，再结合标准化正脸/侧脸照片、预算和侵入性边界生成分阶段方案。

当前原型已经包含：

- 收藏图真实性风险提醒、样本证据墙，以及脸型、眼睛、鼻子、嘴唇、眉毛、肤色和发型偏好。
- 浏览器直接拍摄正脸、左侧脸和右侧脸，并进行照片质量检查。
- 单次/年度预算、恢复期、侵入性、风险、既往项目、决策阶段、动机、保留项和医学复核信息。
- 本人前后拖动对比、五官方向缩略图，以及材料、总量情景、作用区域和分阶段行动方案。

## 本地运行

```bash
npm ci
npm run dev
```

在电脑打开 `http://localhost:4177/`。生产构建：

```bash
npm run build
npm run preview -- --port 4178
```

## 手机安装

最简单的真机方案是把 `dist/` 发布为 HTTPS H5。相机使用浏览器标准 `getUserMedia` 权限：电脑本机的 `localhost` 可以调用；手机通过局域网 HTTP 地址打开时通常不能调用，必须使用可信 HTTPS。

iPhone 用 Safari 打开 HTTPS 地址后选择“分享”→“添加到主屏幕”；Android 用 Chrome 打开后选择“安装应用”。安装后以独立 App 窗口运行，仍然是同一套 Web 代码，适合当前验证阶段。

## GitHub Pages 发布

推送到 `main` 后，GitHub Actions 会自动构建并发布 `dist/`。首次发布前，在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。

站点地址：<https://jrchuckie.github.io/xiaomeishuo/>

## 收藏夹导入

公开分享链接可以被识别，但匿名网页不稳定提供收藏内容。原型默认让用户从小红书分享页批量选择收藏图；内部环境可配置 `VITE_XHS_BOARD_ENDPOINT` 接入用户授权后的收藏夹接口。

## 隐私与边界

- 图片、审美画像、面部基线和方案默认保存在当前设备的 IndexedDB 中。
- 审美识别和面部质量检测在浏览器本地运行；首次使用会下载模型文件。
- 发布到 HTTPS 的是应用代码，不包含测试者或用户照片。
- 产品提供审美决策支持和面诊准备，不构成医疗诊断、处方或效果承诺。
